✏️ MSDS 직접입력 분석

CAS번호와 함량을 직접 입력하여 화관법(K-REACH) · 산안법(KOSHA) 규제 여부를 즉시 조회합니다.

화평법 K-REACH 산업안전보건법 KOSHA 유해화학물질 판정 금지·특별관리물질
사용 방법
① 시트 추가 → ② CAS번호·함량 입력 → ③ 분석 실행
Tab · Enter · ↑↓←→ 키로 셀 이동
Enter/Tab으로 최대값 입력 후 다음 행 자동 생성
+ 행 추가  ·  - 빈 마지막 행 삭제
MSDS명 포함 텍스트 복붙 시 제목 + 구성성분 자동 입력
자주 쓴 CAS번호는 시트 상단 버튼으로 클릭 입력 (3회↑ 자동등록)
범례
완전금지 — 금지물질 (함량 무관) 규제 — 유독·허가·제한·사고대비 기준% — 인체등유해성물질 기존화학 — KE번호 보유 미만(<) / 이하(≤) — 최대값 포함 여부

LLM 프롬프트
첨부한 MSDS PDF(또는 캡처 이미지)를 기준으로,
각 MSDS마다 CAS NO, 최소함량, 최대함량 정보만 추출해 테이블을 생성하라.
 열 구성은 [CAS NO | 최소함량 | 최대함량]이며,
해당 열 헤더 문구는 출력하지 말 것.
 테이블 상단에 MSDS 제목을 1회 출력 후 줄바꿈하고,
각 성분은 한 줄씩 출력할 것.
 하나의 MSDS가 끝나면 공백 1줄을 추가할 것.
 결과 전체를 CSV 코드 형식으로 출력할 것.
 함량은 % 기호 없이 숫자만 사용 (예: 0.1~1 → 0.1,1)
